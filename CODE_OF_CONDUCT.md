# Código de conducta

## Compromiso

Este espacio busca ser útil, directo y respetuoso. Participar en issues, discusiones o cualquier canal del proyecto implica aceptar estas normas.

## Comportamiento esperado

- Tratar a las demás personas con respeto.
- Criticar ideas y comportamientos, no personas.
- Aportar contexto técnico cuando se reporta un problema.
- Aceptar que el mantenedor priorice según su criterio y disponibilidad.
- Respetar la licencia propietaria y la decisión de mantener el código privado.
- No publicar datos personales, números de serie reales ni información confidencial de terceros.

## Comportamiento inaceptable

- Insultos, amenazas, acoso o discriminación por cualquier motivo.
- Spam, promoción comercial no solicitada o suplantación de identidad.
- Publicación de vulnerabilidades sin seguir el canal privado.
- Presión insistente para obtener acceso al código, a los servidores o a datos privados.
- Ingeniería inversa, redistribución no autorizada o solicitudes para vulnerar la licencia.
- Compartir exploits, malware o instrucciones para dañar sistemas ajenos.

## Aplicación

El mantenedor puede editar, cerrar o eliminar cualquier contribución que incumpla estas normas, y bloquear a quien las incumpla de forma reiterada o grave. Las decisiones se comunican con una explicación breve cuando es posible.

## Reportar un problema de conducta

Escribe a **JonathanHurtadoDev@proton.me** con el asunto `[CONDUCTA] USBGuardGo`. Incluye qué ocurrió y enlaces o capturas si existen. El reporte se tratará de forma confidencial.

## Alcance

Estas normas se aplican a los espacios del proyecto en GitHub y a cualquier interacción pública en la que se represente a USBGuardGo.
